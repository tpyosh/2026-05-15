# Gear

## 管理方針

装備の詳細管理は `data/gear.csv` を使います。このファイルでは、カテゴリ、必須有無、数量、所有者、梱包状況を管理します。

## 優先度

1. 睡眠と防寒
2. 雨対策
3. 調理と水
4. 照明
5. 救急と衛生
6. 片付け

## 追加検討リスト

- 季節に合う寝袋
- 地面の冷えを防ぐマット
- 雨天時のタープ
- 夜間移動用のヘッドランプ
- 子どもや初心者向けの予備防寒具
- 濡れたものを分ける袋
- 強風対策用の鍛造ペグ、追加ガイロープ、ペグハンマー
- 焚き火台と耐熱シート
- ゴミ持ち帰り用の袋

## パッキング確認

- 必須装備は出発前日までに所有者を決める。
- 当日朝に `packed` 列を `yes` に更新する。
- 借り物は返却先と期限を `notes` に書く。
- テントの貸出はないため、宿泊する場合は必ず持参する。
- 貸出資材を利用した場合は、返却時に洗浄する。
