# Gear

共有装備の人間向けチェックリストです。
台帳の正本は `data/gear.csv` です。担当、数量、梱包状況を変えたら両方を同じ変更で更新します。

## 管理範囲

- ここでは複数人で共有する持ち物だけを扱う。
- 各自の衣類、寝具、洗面用品、常備薬は個人管理とする。
- `担当未定` は出発前日までに解消する。
