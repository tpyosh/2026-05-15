# Gear

参加者別の持ち物一覧です。
共有装備の台帳の正本は `data/gear.csv` です。担当、数量、梱包状況を変えたら両方を同じ変更で更新します。

## 管理範囲

- ここでは複数人で共有する持ち物を中心に扱う。
- 各自の衣類、寝具、洗面用品、常備薬は個人管理とする。
- `担当未定` は出発前日までに解消する。

| タイミング | 確認すること |
| --- | --- |
| 予約前 | フリーサイトと車台数に対して、タープ、テーブル、焚き火台が過不足ないか |
| 1週間前 | 担当未定をなくす |
| 前日 | `data/gear.csv` の `packed` を更新する |
| 帰宅後 | 借り物の返却、濡れた装備の乾燥 |
