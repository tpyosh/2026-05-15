# Budget

## 管理方針

費用の一覧は `data/budget.csv` で管理します。概算、実績、支払者、割り勘方法を分けて記録します。

## 予算カテゴリ

- キャンプ場利用料（入場料 + サイト利用料）
- 交通費
- 食材
- 燃料、炭、薪、消耗品
- シャワー、温泉、観光
- 予備費

## 尾高高原キャンプ場の料金メモ

詳細は `data/site-fees.csv` を正とする。

| 項目 | 金額 | 条件 |
| --- | --- | --- |
| 入場料 大人 | 200円 | 中学生以上 |
| 入場料 子ども | 100円 | 小学生。小学生未満は無料 |
| オートサイト | 5,000円 | 1区画、AC電源付き |
| フリーサイト | 3,500円 | テント1張り。タープ追加は1張り500円 |
| 薪 | 600円 | 1束 |
| 炭 | 700円 / 1,400円 | 3kg / 6kg |
| コインシャワー | 200円 | 3分 |

## 精算ルール

- 事前に割り勘単位を決める。
- 車ごとの燃料費や高速料金は、車両単位で分けるか全体で分けるか決める。
- 立替者と金額は当日中に記録する。
