# 食べる量の見積もり

更新日: 2026-05-16

## 位置づけ

このファイルは `docs/recipes/` に登録されているメニューを全部作った場合に、どのくらい食べることになるかを見るための概算です。
実際に作るメニューが確定しているわけではないため、`data/meal-plan.csv` が確定したら対象メニューだけで再計算します。
ホットケーキは朝食または軽食として量を維持し、それ以外の算出可能なメニューはコリアンバーベキューを含めて合計で1人当たり約1,300gになるように調整しています。

## 算出ルール

- 対象は各レシピの `Mandatory` と `Required` の食材です。
- `Advisary`、調理用品、燻製チップ、アルミホイルなど食べないものは含めません。
- 骨付き肉や貝は、食べる部分だけを可食部として見積もります。
- `適量` や商品差で量が決まるものは、合計から外すか、料理全体に対する影響が小さいものとして扱います。
- 調理中の蒸発や焼き縮みは厳密には追わず、皿に出て食べる量の目安として丸めています。

主な換算:

| 食材 | 換算 |
| --- | --- |
| 米 | 1合150g、2合で300g |
| 炊飯用の水 | パエリアでは米に吸わせる分として可食部に含める |
| あさり | 殻付き重量の25%を可食部として見積もる |
| 骨付き豚スペアリブ | 骨付き重量の60%を可食部として見積もる |
| 玉ねぎ | 1個200g、1/2個100g |
| パプリカ | 1個150g |
| ミニトマト | 1個15g |
| にんにく | 1片5g |
| レモン・ライム | 1個の果汁30g、1/2個の果汁15g |
| 卵 | 1個50g |
| トルティーヤ | 1枚25g |
| サルサソース | 1瓶240g |
| ソーセージ | 1本40〜50g |

## 全体量

登録済みレシピを全部作った場合の合計です。

| 対象 | 合計可食部 | 1人当たり |
| --- | ---: | ---: |
| ホットケーキ以外の算出可能な7メニュー合計 | 約4.0kg | 約1.3kg |
| ホットケーキ | 約0.85〜0.95kg | 約0.28〜0.32kg |
| ホットケーキを含む算出可能な8メニュー合計 | 約4.8〜4.9kg | 約1.6〜1.65kg |

この合計には、アクアパッツァのバゲット、ホットケーキのシロップ類、各レシピの `Advisary` は含めていません。
