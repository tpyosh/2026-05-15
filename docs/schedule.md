## 出発前チェック

- 予約状況とキャンプ場の営業状況を確認する。
- 天気、風速、警報を確認する。
- 交通状況と給油場所を確認する。
- `data/gear.csv` の担当未定を潰す。
- `data/meal-plan.csv` のメニューと買い出し品を確定する。
- イオンモール東員で買うものと持参するものを分ける。

## 雨天時の判断

| 状況 | 判断 |
| --- | --- |
| 小雨 | タープ前提で実施可否を判断 |
| 強風 | タープ、焚き火、炭火調理を見直す |
| 雷、大雨、警報 | 延期または中止を検討 |
| キャンプ場閉場 | 中止または延期 |
