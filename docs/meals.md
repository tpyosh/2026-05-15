# Meals

## 方針

- 調理時間を短くし、設営と撤収に余裕を残す。
- 生鮮食品は保冷できる量に抑える。
- 雨天時でも作れるメニューを優先する。
- 子ども、アレルギー、苦手な食材がある場合は `data/participants.csv` に記録する。

## 献立

献立と食材は `data/meal-plan.csv` で管理します。
食べたいものの候補整理は `docs/food-wishlist.md` で管理します。

| 食事 | 方針 |
| --- | --- |
| 1日目昼 | 移動中または買い出しで簡単に済ませる |
| 1日目夜 | メイン料理を1つに絞る |
| 2日目朝 | 撤収しやすい簡単なものにする |

## 買い出しメモ

- 買い出し場所: イオンモール東員
- 開始時刻: 10:00
- 肉、魚、野菜
- 米、パン、麺
- 調味料
- 飲料水
- コーヒー、お茶
- 氷、保冷剤
- キッチンペーパー、アルミホイル、ラップ
- 洗剤、スポンジ

## 買い出し前に決めること

- 1日目昼食をイオンモール東員で済ませるか、キャンプ場到着後に食べるか。
- 氷と保冷剤を買う量。
- 薪・炭を現地購入にするか、買い出し時に購入するか。

## 食品安全

- 肉や魚は保冷を優先する。
- まな板とトングは生肉用と食事用を分ける。
- 食材は夜間に外へ放置しない。

## 現地で使える可能性があるもの

- 薪、炭3kg、炭6kgは現地販売あり。
- まな板・包丁、鉄板、金網、飯ごう、大鍋、小鍋は有料貸出あり。
- 貸出資材は返却前に洗浄が必要。
