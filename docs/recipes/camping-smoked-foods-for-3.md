# 簡易燻製盛り合わせ

## 想定人数

成人男性3人前相当

## 概要

チーズ、ソーセージ、ゆで卵、ナッツなど、加熱済みまたは扱いやすい食材を短時間で燻すキャンプ向けの簡易燻製。
生肉や生魚の本格燻製には寄せず、失敗しにくいおつまみ系の構成にする。

## 向いているシーン

- 夕食前後のつまみ
- メイン料理の待ち時間
- 火を囲みながら少しずつ食べる料理

## 難易度

低〜中

## 所要時間

約30〜45分

## 必要な調理器具

- 簡易スモーカー、または蓋付き鍋
- 網
- アルミホイル
- トング
- バーナーまたは安定した加熱手段
- 耐熱手袋または軍手

## 材料

### Mandatory

| 材料 | 分量 |
| --- | --- |
| 燻製チップ | 2つかみ程度 |
| プロセスチーズまたはベビーチーズ | 約150g |
| ソーセージ | 6〜9本 |
| ゆで卵 | 3個 |

### Required

| 材料 | 分量 |
| --- | --- |
| ベーコン | 約150g |
| ミックスナッツ | 約80g |
| アルミホイル | 適量 |

### Advisary

| 材料 | 分量 |
| --- | --- |
| ちくわ | 3〜4本 |

| 黒こしょう | 適量 |
| はちみつ | 少量 |
| クラッカー | 適量 |

## 下準備

- チーズは溶けやすいため、大きめに切るか個包装のまま直前まで保冷する。
- ゆで卵は殻をむき、水分を拭く。
- ソーセージ、ベーコン、ちくわ等の表面の水分を拭く。
- スモーカーまたは鍋の底にアルミホイルを敷き、燻製チップを置く。
- 食材は網の上に間隔を空けて並べる。

## 調理手順

1. スモーカーまたは蓋付き鍋にアルミホイルと燻製チップをセットする。
2. 網を置き、食材を並べる。
3. 蓋をして中火で加熱し、煙が出始めるのを待つ。
4. 煙が出たら弱火に落とす。
5. 10〜20分ほど燻す。
6. チーズが溶けそうな場合は早めに取り出す。
7. ソーセージ、卵、ベーコンは色と香りを見て取り出す。
8. 取り出した食材を数分置いて、煙の香りを落ち着かせる。

## 火加減の目安

- 煙を出すまでは中火。
- 煙が出た後は弱火。
- チップを燃やすのではなく、煙を出す程度に抑える。

## 失敗しやすいポイント

- 火が強すぎると燻製チップが燃えて苦味が出る。
- チーズは加熱しすぎると溶け落ちる。
- 食材を詰め込みすぎると煙が回りにくい。
- 水分が多い食材は香りが乗りにくい。
- 長く燻しすぎると苦くなる。

## キャンプ運用上の注意

- 煙が出るため、キャンプ場のルールと周囲の距離を確認する。
- 風が強い場合は火力が安定しにくい。
- 生肉や生魚の燻製にはしない。
- 食材は加熱済みまたは短時間加熱で食べられるものを中心にする。

## 後片付けの注意

- 燻製チップの燃え残りは完全に消火してから処理する。
- アルミホイルを敷いておくと鍋底の汚れを減らせる。
- 燻製後の器具には匂いが残りやすいため、収納前に拭く。
