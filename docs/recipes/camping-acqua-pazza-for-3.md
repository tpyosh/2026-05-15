# キャンプ用アクアパッツァ

## 想定人数

成人男性3人で複数メニューと分ける量

## 概要

キャンプ場でフライパン、スキレット、浅型鍋、または大型メスティンを使って作るアクアパッツァです。
焚き火、炭火、ガスバーナー、カセットコンロのいずれでも調理できます。
現地では魚介と野菜を入れて蒸し煮にするだけに近い運用にします。

成人男性3人で、肉料理や主食と並べる魚介メニューとして食べる想定です。
魚は丸魚でも作れますが、キャンプでは扱いやすさを考えて切り身を基本案にします。

## 分量の目安

- 白身魚の切り身: 2切れ、合計220〜280g程度
- あさり: 120〜150g程度
- 事前準備: 10〜20分程度
- 現地での調理: 15〜25分程度

魚の厚み、貝の量、火力によって調理時間は変わります。
時間だけで判断せず、魚と貝に十分に火が通ったことを確認します。

- ガスバーナー、カセットコンロ、炭火台、焚き火台のいずれか

- まな板

## 家での事前準備

1. あさりは砂抜きしておく。購入時点で砂抜き済みの場合も、必要に応じて軽く確認する。
2. 白身魚は水分をキッチンペーパーで拭き、軽く塩を振る。
3. ミニトマトは洗ってヘタを取る。
4. にんにくは薄切り、または潰しておく。
5. レモンはくし切りにしておく。
6. 魚介類はクーラーボックスで冷蔵状態を保って持参する。
7. 白ワイン、水、調味料は小分け容器に入れておくと現地で扱いやすい。

## キャンプ場での調理手順

1. フライパンまたは鍋にオリーブオイルとにんにくを入れ、弱火〜中火で香りを出す。
2. 魚を皮目から入れ、表面に軽く焼き色をつける。
3. あさり、ミニトマト、白ワイン、水を加える。
4. 蓋をして中火で蒸し煮にする。
5. あさりの口が開き、魚に火が通るまで加熱する。
6. 味を見て、塩と黒こしょうで調整する。
7. 仕上げにオリーブオイルを少量回しかけ、パセリとレモンを添える。
8. 煮汁はバゲットにつけて食べる。

## 火加減のコツ

- にんにくは焦がすと苦くなるため、最初は弱火〜中火にする。
- 魚は崩れやすいので、焼いている途中で何度も動かさない。
- 焚き火や炭火の場合は火力が強くなりすぎやすいので、鍋を火から少し離せる位置を確保する。
- 水分が少なくなったら、水または白ワインを少量足す。
- 蓋がない場合はアルミホイルで代用する。

## 安全上の注意

- 魚介類は傷みやすいので、調理直前までクーラーボックスで保冷する。
- あさりは加熱しても口が開かないものは食べない。
- 生魚を扱ったまな板、ナイフ、手で、そのまま完成品やパンを触らない。
- 残った煮汁を長時間常温に置かない。
- 焚き火や炭火で調理する場合は、鍋の安定性と火傷に注意する。
