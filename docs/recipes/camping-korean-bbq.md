# コリアンバーベキュー

## 想定人数

成人男性3人で複数メニューと分ける量

## 概要

市販の味付き肉、またはたれ付き焼肉用の肉を使って、フライパン、スキレット、鉄板、または焼き網で焼くコリアンバーベキューです。
他の肉料理や主食と並べる前提で、量は1人あたり150gにします。

## 必要な調理器具

- フライパン、スキレット、鉄板、または焼き網のいずれか
- トング
- ガスバーナー、カセットコンロ、炭火台、焚き火台のいずれか
- クーラーボックス
- 保冷剤
- 肉用の保存袋、または密閉容器
- 皿、または取り分け容器

## 材料

### Mandatory

| 材料 | 分量 |
| --- | --- |
| コリアンバーベキュー用の味付き肉、またはたれ付き焼肉用の肉 | 450g |

### Required

なし

### Advisary

なし

## 下準備

- 肉は調理直前までクーラーボックスで保冷する。
- 味付き肉でない場合は、買い出し時にコリアンバーベキュー向けのたれ付き商品を選ぶ。

## 調理手順

1. フライパン、スキレット、鉄板、または焼き網を中火で温める。
2. 肉を広げ、重なりすぎないように焼く。
3. 片面に焼き色がついたら返す。
4. 中心まで十分に火が通ったことを確認する。
5. 焦げそうな場合は火を弱める、または火から少し離す。

## 安全上の注意

- 生肉を触ったトングや皿を、焼き上がった肉にそのまま使わない。
- 肉は中心までしっかり加熱する。
- 味付き肉は焦げやすいため、強火に当て続けない。
