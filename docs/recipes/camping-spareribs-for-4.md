# キャンプ用スペアリブ 4人分

## 概要

キャンプ場で炭火、焚き火台、BBQグリル、鉄板、または網を使って焼くスペアリブです。
家で下味をつけて持参し、現地では焼くだけに近い運用にします。
4人でメインメニューの一つとして食べる想定です。

キャンプでは火加減が安定しにくいため、焦げ防止と火通り確認を優先します。

## 分量の目安

- 骨付き豚スペアリブ: 1人あたり250〜300g程度
- 合計量: 1.0〜1.2kg程度
- 事前漬け込み: 半日〜一晩
- 現地での焼き時間: 30〜45分程度

肉の厚み、骨の大きさ、火力によって調理時間は変わります。
時間だけで判断せず、中心まで十分に火が通ったことを確認します。

## 調理器具

- BBQグリル、焚き火台、または炭火用コンロ
- 焼き網、または鉄板
- トング
- アルミホイル
- チャック付き保存袋、または密閉容器
- クーラーボックス
- 保冷剤
- キッチンペーパー
- 肉用温度計があれば望ましい
- 使い捨て手袋があると便利

## 家での事前準備

1. スペアリブの表面の水分をキッチンペーパーで拭く。
2. 肉に塩と黒こしょうをなじませる。
3. 醤油、はちみつ、ケチャップ、ウスターソース、酒、にんにく、しょうが、油を混ぜて漬けだれを作る。
4. 保存袋に肉と漬けだれを入れてよく揉み込む。
5. 冷蔵庫で半日〜一晩置く。
6. キャンプ当日はクーラーボックスで冷蔵状態を保って持参する。

## キャンプ場での調理手順

1. 焼く30分前を目安にクーラーボックスから出し、肉の冷たさを少し取る。ただし長時間常温放置しない。
2. 炭火の場合は、炭を多めに置く強火ゾーンと炭を少なめにする弱火ゾーンを作る。
3. まず弱火〜中火でじっくり火を通す。
4. 焦げやすい漬けだれなので、最初から強火に当てすぎない。
5. 中まで火が入りにくい場合は、アルミホイルで包んで蒸し焼きにする。
6. 仕上げに網の上で表面を焼き、香ばしさを出す。
7. 中心まで十分に火が通ったことを確認する。肉用温度計がある場合は中心温度を確認する。
8. 焦げそうな場合は火から遠ざける、またはアルミホイルで保護する。

## 火加減のコツ

- はちみつ、ケチャップ、ソースを含む漬けだれは焦げやすいため、最初は弱火〜中火で焼く。
- 炭火では強火ゾーンと弱火ゾーンを分け、焦げそうな肉は弱火ゾーンに移す。
- 骨の近くは火が入りにくいため、表面の焼き色だけで判断しない。
- アルミホイルで包むと蒸し焼きになり、中まで火を入れやすい。
- 仕上げだけ強めの火に当てると、焦がしすぎず香ばしさを出しやすい。

## 安全上の注意

- 生肉を触ったトングや皿を、焼き上がった肉にそのまま使わない。
- 漬けだれを仕上げに使う場合は、必ず加熱する。
- キャンプ場では肉を常温に長く置かない。
- 豚肉は中心までしっかり加熱する。
- 焦げが強くなりすぎる場合は、火力を落とすかアルミホイルで保護する。
