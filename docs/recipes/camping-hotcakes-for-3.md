# ホットケーキ

## 想定人数

成人男性3人前相当

## 概要

ホットケーキミックスを使い、キャンプの朝食または軽食として作る簡易ホットケーキ。
本格的な製菓ではなく、最小限の器具で失敗しにくく焼くことを優先する。

## 向いているシーン

- 朝食
- 軽食
- 子どもや甘いものが欲しい人向けの追加メニュー

## 難易度

低

## 所要時間

約25〜35分

## 必要な調理器具

- フライパン
- ボウル
- 泡立て器、箸、またはスプーン
- フライ返し
- 計量カップ
- おたままたは大きめのスプーン
- バーナーまたは安定した加熱手段

## 材料

### Mandatory

| 材料 | 分量 |
| --- | --- |
| ホットケーキミックス | 約450g |
| 牛乳または水 | 約330〜350ml |
| 油またはバター | 適量 |

### Required

| 材料 | 分量 |
| --- | --- |
| 卵 | 2〜3個 |
| メープルシロップ、はちみつ、またはジャム | 適量 |

### Advisary

| 材料 | 分量 |
| --- | --- |
| バター | 追加用 |
| チョコソース | 適量 |
| バナナ | 1〜2本 |
| ミックスナッツ | 適量 |
| 粉糖 | 適量 |

## 下準備

- ホットケーキミックス、卵、牛乳または水を混ぜる。
- 混ぜすぎると固くなりやすいため、多少ダマが残る程度で止める。
- 牛乳を使わない場合は水で代替する。
- フライパンに油またはバターを薄くなじませる。

## 調理手順

1. フライパンを弱火〜中弱火で温める。
2. 生地を小さめに流し入れる。
3. 表面に小さな泡が出て、縁が乾いてきたら裏返す。
4. 裏面を1〜2分焼く。
5. 焦げそうな場合は火から少し離すか、火を弱める。
6. 焼けたものから皿に移し、シロップやジャムをかけて食べる。

## 火加減の目安

- 基本は弱火〜中弱火。
- 強火にすると表面だけ焦げて中が生焼けになりやすい。
- フライパンが熱くなりすぎたら、一度火から外して温度を下げる。

## 失敗しやすいポイント

- 生地を大きく流しすぎると裏返しにくい。
- 強火で焼くと焦げやすい。
- 混ぜすぎると食感が重くなる。
- フライパンに油が多すぎると表面が揚げ焼きのようになる。

## キャンプ運用上の注意

- 朝食運用なら、粉類とトッピングは前日にまとめておくとよい。
- 牛乳の保冷が面倒な場合は水で作る。
- 1枚を大きくせず、小さめに複数枚焼く方が失敗しにくい。
- 洗い物を減らす場合は、ボウルではなく厚手の袋で混ぜる運用も可。

## 後片付けの注意

- 生地が乾くと落ちにくいため、ボウルや道具は早めに水につける。
- フライパンの焦げ付きはキッチンペーパーで拭いてから洗う。
- シロップ類は漏れやすいため、収納時に蓋を確認する。
