# オレンジチキン

## 想定人数

成人男性3人前相当

## 概要

市販のオレンジチキンシーズニングを使い、鶏もも肉を焼き揚げ風にして絡めるキャンプ向けの簡易オレンジチキン。
大量の揚げ油は使わず、フライパンで再現しやすい方式にする。

## 向いているシーン

- 夕食のメイン
- 米に合う肉料理を作りたいとき
- 市販シーズニングで味を安定させたいとき

## 難易度

中

## 所要時間

約35〜45分

## 必要な調理器具

- フライパンまたはスキレット
- ボウルまたはポリ袋
- 包丁
- まな板
- トングまたは菜箸
- 計量カップ
- キッチンペーパー
- バーナーまたは安定した加熱手段

## 材料

### Mandatory

| 材料 | 分量 |
| --- | --- |
| 鶏もも肉 | 約900g |
| 市販オレンジチキンシーズニング | 3人前相当、または鶏肉900gに対応する量 |
| 片栗粉 | 約60g |
| 油 | 大さじ3〜5 |
| 水 | シーズニング指定量に合わせる |

### Required

| 材料 | 分量 |
| --- | --- |
| 玉ねぎ | 1個 |
| パプリカ | 1個 |
| 塩 | 少量 |
| 黒こしょう | 少量 |

### Advisary

| 材料 | 分量 |
| --- | --- |
| ブロッコリー | 1/2〜1株、または冷凍品適量 |
| 白ごま | 適量 |
| 青ねぎ | 適量 |
| レモン | 1個 |
| 白米またはパン | 必要に応じて |

## 下準備

- 鶏もも肉は一口大に切る。
- 鶏肉に塩、黒こしょうを軽く振る。
- 玉ねぎとパプリカは食べやすい大きさに切る。
- 鶏肉に片栗粉をまぶす。ポリ袋を使うと洗い物を減らせる。
- 市販シーズニングはパッケージ指定に従い、水などで溶いておく。

## 調理手順

1. フライパンに油を多めに入れ、中火で温める。
2. 片栗粉をまぶした鶏肉を並べ、表面がカリッとするまで焼く。
3. 鶏肉の中心まで火が通ったら、一度取り出す。
4. 同じフライパンで玉ねぎとパプリカを炒める。
5. 鶏肉を戻し、市販オレンジチキンシーズニングを加える。
6. 弱火〜中弱火で全体に絡める。
7. ソースが煮詰まりすぎる場合は少量の水で調整する。
8. 好みで白ごま、青ねぎ、レモンを加える。

## 火加減の目安

- 鶏肉を焼く工程は中火。
- ソースを絡める工程は弱火〜中弱火。
- ソース投入後は糖分で焦げやすいため、強火にしない。

## 失敗しやすいポイント

- 鶏肉を詰め込みすぎると焼き色がつかず、蒸し焼きになる。
- 片栗粉が多すぎると粉っぽくなる。
- ソースを強火で煮詰めると焦げやすい。
- シーズニングの塩分や濃度は商品差があるため、最後に水分量で調整する。

## キャンプ運用上の注意

- 鶏肉は保冷し、中心まで十分に加熱する。
- 大量の揚げ油は使わず、焼き揚げ程度にする。
- 油はねがあるため、火元の安定した場所で調理する。
- 白米と合わせる場合は、炊飯側のタイミングと合わせる。

## 後片付けの注意

- ソースが焦げ付く前にフライパンを拭き取る。
- 油をその場に捨てず、キッチンペーパー等に吸わせて処理する。
- シーズニングソースが付いた器具は早めに洗う。
