# Food Wishlist

食べたいものを思いついた時点で追加していく専用リストです。ここでは候補を広く集め、実際に採用するメニューや買い出し内容は `data/meal-plan.csv` に確定情報として移します。

## 記録ルール

- 思いつき段階でもそのまま追加する。
- 迷っているものはメモ欄に条件を書く。
- 実際に採用したら状態を更新する。
